Features

Everything your AI agent needs to remember

Production-grade memory infrastructure with enterprise features, built for the MCP ecosystem.

Dual Memory

Episodic (Qdrant vector) + semantic (NetworkX graph). Two complementary systems fused by LLM reasoning, just like human memory.

Entity-Gated Ingestion

Only stores messages containing real entities. System prompts, trivial chat, and noise are filtered out automatically.

Real-Time Capture

Session watchers monitor IDE conversations live. Works with Claude Code, OpenClaw, Cursor via inotify/watchdog.

Federated Search

Query mem0, LightRAG, Graphiti, and custom providers in parallel. Auto-discovers knowledge sources on your machine.

Enterprise Ready

Multi-tenancy, JWT + RBAC auth, Redis caching, rate limiting, audit trail, resource tiers, and OpenTelemetry observability.

Multi-Surface API

CLI (Typer), MCP Server (stdio), HTTP API (FastAPI), and WebSocket. Pick the interface that fits your stack.

How It Works

Three steps to persistent memory

From installation to full AI memory in under five minutes.

1

Install

One pip command. Embedded Qdrant and SQLite included — no external services required to start.

pip install engram-mem
2

Connect

Add engram as an MCP server in your AI tool's config. Claude Code, Cursor, or any MCP-compatible client.

engram serve --mcp
3

Remember

Your AI agent now has persistent memory. It remembers context, preferences, and knowledge across sessions.

engram recall "project setup"

Quick Start

Up and running in minutes

Simple CLI commands or integrate via MCP, HTTP, or WebSocket.

CLI Usage
# Install $ pip install engram-mem # Store a memory $ engram remember "User prefers dark theme" # Recall relevant memories $ engram recall "UI preferences" # Start MCP server for AI agents $ engram serve --mcp # Start HTTP API server $ engram serve --http --port 8100 # Ingest a session file $ engram ingest session.jsonl
MCP Config (Claude Code)
// ~/.claude/settings.json { "mcpServers": { "engram": { "command": "engram", "args": ["serve", "--mcp"] } } } // Your AI agent now has access to: // - engram_remember // - engram_recall // - engram_ask // - engram_add_entity // - engram_add_relation // - engram_feedback // - engram_session_start/end // - ... and 15+ more tools
