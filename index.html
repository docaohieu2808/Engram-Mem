Persistent memory for AI agents

Vector search for conversations. Knowledge graph for entities and relationships. One install.

$ pip install engram-mem
terminal
$ engram remember "Use PostgreSQL for the auth service, Redis for sessions"
✓ Stored (entities: PostgreSQL, Redis, auth service)
$ engram recall "what database should I use for auth?"
→ Use PostgreSQL for the auth service, Redis for sessions
  [preference] confidence: 0.92 | 2 hours ago
Why

Your AI forgets everything. Claude Code, Cursor, Copilot — all of them start each session from zero. Useful for isolated tasks. Frustrating for ongoing projects where context matters.

Engram fixes that. Dual memory store: vector search for conversations and decisions, knowledge graph for entities and their relationships. Your agent remembers what you said, who you mentioned, and what you decided — across sessions.

Works with what you use. MCP server for Claude Code and Cursor. HTTP API for custom agents. CLI for scripts. One pip install, working in 5 minutes.

Code
Add to Claude Code json
{
  "mcpServers": {
    "engram": {
      "command": "engram-mcp"
    }
  }
}
Use in your agent python
import httpx

api = "http://localhost:8757"

# store a decision
httpx.post(f"{api}/api/v1/remember",
  json={"text": "use postgres for auth"})

# retrieve it later
r = httpx.post(f"{api}/api/v1/recall",
  json={"query": "auth database"})
print(r.json()["results"])
